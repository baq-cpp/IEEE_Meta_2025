
# BroncoVerse

## Summary
This is a Virtual Reality (VR) lab simulation that combines the authenticity of physical labs with the accessibility of remote learning.  
This lab is based on the Cal Poly Pomona course ECE 3300/L - Digital Circuit Design Using Verilog.

## Configuration
These instructions have only been tested on the Meta Quest 3 and Meta Quest Pro.

### For Users
1. Enable Developer Mode on the headset
   - requires a Meta Developer Account
2. Download the .apk
3. Install it on the headset
4. Launch it from Unknown Sources

### For Developers
## Headset
1. Enable Developer Mode on the headset
2. Set up Android build support in Unity 6.1 (6000.1.7f1), install Microsoft VS Community (2022 or higher)
3. Configure XR + Quest settings
4. Build an APK
5. Install it on the headset
6. Launch it from Unknown Sources

## Simulation
1. Activate Meta XR Simulator - Meta/Meta XR Simulator/Activate
2. Set the scene to Assets/Scenes/Schematic_1_Demo
